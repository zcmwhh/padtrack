零、控制中心（推荐入口）
────────────────────────────────────────────
双击【控制中心.lnk】或【控制中心.vbs】（零闪），一个窗口搞定所有事。

想放桌面：把【控制中心.lnk】拖到桌面即可，图标是自带的，不会变成白纸。

窗口里的按钮：
  启动（普通权限）   起服务，够用 90% 场景
  以管理员启动       需要操作 WattToolkit / Steam++ 这类管理员程序时才用
  停止服务           停掉；杀不掉会自动弹 UAC 提权
  USB 直连           建 adb 隧道，延迟 1~2ms
  打开平板页面       在本机浏览器先自测
  使用说明           打开这份文件
  打开日志           看 padtrack.log
  刷新状态           立刻重新采集一次

平板地址那一行可以直接点，点了就复制到剪贴板。

状态灯：绿=正常 / 黄=需要注意（未运行、映射没建）/ 灰=还没数据。

原来的 停止.bat / 管理员启动.bat / USB直连.bat 都还在，双击也能用。
PadTrack —— 把安卓平板/手机当电脑触控板用
================================================

【这是什么】
电脑上跑一个小程序，平板用浏览器打开一个网页，就能当触控板、键盘用。
平板不用装 App，不用 root，只要和电脑连同一个 WiFi。

【三步开始】

1. 双击 PadTrack.exe（新版不会再弹出黑色命令行窗口）
   - 会弹出一个黑色窗口，里面有类似这样的两行：
       平板浏览器打开:  http://192.168.1.10:8765/?k=4821
   - 第一次运行 Windows 会问"是否允许访问网络"，务必勾选【专用网络】并点允许。
   - 如果窗口里没显示地址，看同目录下的【当前地址.txt】。

2. 平板连上和电脑同一个 WiFi（不要连访客网络）。
   用 Chrome 或 Edge 打开窗口里那个地址（要带上 ?k= 后面那串数字）。

3. 搞定。手指在平板上划，电脑上的光标就动。

【常用手势】

  单指滑动          移动光标
  轻点              左键单击
  双击后拖 / 按住拖  拖动窗口
  双指上下滑        滚动（松手有惯性）
  双指捏合          缩放
  双指轻点          右键
  三指轻点          开始菜单
  三指上滑          任务视图
  三指下滑          显示桌面
  三指左右滑        切换窗口

【打字】

  右上角键盘按钮打开键盘，四种形态（每种键盘顶部都能直接切换）：
    - 抽屉键盘（下半屏）
    - 全屏（键盘上划动就是触控板）
    - 分屏（左边键盘，右边小触控板）
    - 环绕（上面打字区，下面 3:2 触控板，两侧功能键）
  默认走【电脑的输入法】：在平板上打拼音，候选词出现在电脑屏幕上，
  用键盘上的数字键选词。这样中文输入法的词库和习惯都是电脑那套。

  右上角数字图标可以调出右侧小键盘，做表格、输数字更方便。

【媒体胶囊】

  顶部中间那颗胶囊显示当前播放的歌曲：
    - 收起态：封面 + 歌名 + 律动条 + 播放/暂停
    - 点一下展开：歌名、歌手、可拖动的进度条、随机 / 上一首 / 播放 /
      下一首 / 循环 / 歌单，6 秒不操作自动收起
    - 点「歌单」可以看到网易云里的歌单和曲目

  两点要知道：
    - 不同播放器能力不同，按钮会如实置灰，不会假装成功
    - 网易云音乐不注册系统媒体控制，所以它没有精确进度、不能拖进度条、
      不能切随机/循环；反过来，只有它能读到本地歌单

【歌词】

  放歌时会显示滚动歌词，当前行高亮。
  设置里有两个开关：
    - 滚动歌词：左边那一列
    - 封面背景（模糊）：把当前专辑封面糊成整屏底色
  歌词对不齐时，设置里的「−5 秒 / +5 秒」可以手动微调。

【停止】

  关掉黑色窗口，或双击【停止.bat】。

【连不上时】

  1. 确认平板和电脑在同一 WiFi，且路由器没开"AP 隔离/访客网络"。
  2. 电脑防火墙要放行：第一次弹窗时勾"专用网络"。如果误点了取消，
     用管理员身份运行 CMD，执行一次：
        netsh advfirewall firewall add rule name="PadTrack" dir=in action=allow protocol=TCP localport=8765
  3. 电脑开着 VPN 的话先关掉，VPN 会拦截局域网。
  4. 地址里的 ?k= 四位数字必须和窗口里一致。

【能连上但光标不动】

  PadTrack 用普通用户权限启动即可。如果要操作的程序是以管理员身份运行的
  （比如 WattToolkit / 前 Steam++、某些系统工具），PadTrack 也要用管理员
  身份运行，否则 Windows 会丢掉注入的输入：光标可能能动，但点不动，
  或者完全不动。用同目录下的【管理员启动.bat】一下就好。

  设置面板里有【输入自检】：显示当前权限，点"检测"会真的挪一下光标并
  给出结论。滑不动的时候先点它，能分清是权限问题还是别的问题。

【提示】

  - 这是 Python 打包的程序，个别杀毒软件可能误报，选择"信任/允许"即可。
  - Windows 可能提示"未知发布者"，点"更多信息 → 仍要运行"。
  - 端口 8765 被占用时会先等几秒，仍占用才换 8766、8767……以【当前地址.txt】为准。
  - 想固定访问码：删掉 key.txt 会重新生成，或者直接用命令行启动：
        PadTrack.exe --key 1234

七、更跟手：用 USB 线直连（可选）
────────────────────────────────────────────
WiFi 会带来 10~30ms 的延迟和抖动，手指滑动会觉得"粘"。
插 USB 线可以把这个延迟压到 1ms 以内：

1. 平板上打开「开发者选项 → USB 调试」
2. 用数据线把平板接到电脑
3. 双击本目录里的【USB直连.bat】
   （第一次运行会自动下载 adb，约 8MB）
4. 平板浏览器打开它打印的地址：
       http://127.0.0.1:8765/?k=你的访问码

这个地址走 USB 线，不经过 WiFi。
拔线或重启电脑后要重新运行一次【USB直连.bat】。

小提示：左上角那个延迟数字，WiFi 一般 20~30ms，USB 直连应该在 2ms 以内。
